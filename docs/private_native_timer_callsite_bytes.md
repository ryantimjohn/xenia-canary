# Private native timer callsite bytes

`native_timer_callsite_bytes` defaults false. Windows x64 only, at the existing undefined export path. No shim/timer/wait/event/return/timing behavior changes. Original undefined-call fatal/log/return0 fallback and native_timer_undefined_trace are unchanged; XPOLL001 is unchanged.

Select only undefined function metadata KeSetTimer/ordinalA6/import82CE8A6C and exact full64 saved LR000000008286EE20, plus pointer identity against the current processor's registered xboxkrnl table. A process-wide lock-free one-shot is claimed before memory qualification, reads or failure output. Failure consumes it; no retry. Once consumed, the hook returns before metadata/context/QPC/log inspection. Default-off makes no observer call or output.

Require the current PPCContext thread_state's Processor identity to equal context->processor. Obtain Memory through that actual thread_state->processor()->memory() C++ accessor, require its identity matches ThreadState::memory(), and use Memory::virtual_membase(), not context layout, RSI, ASLR, PDB/static lookup or a guessed mapping address. The fixed guest window8286ECA0..8286EE9F is512B (LR-384 through LR+127), below E0000000; Windows Memory::TranslateVirtual for this range is precisely actual base+VA. Integer overflow/null-base checks precede any address query.

One VirtualQuery must cover all512B in a committed single readable region with no PAGE_GUARD/NOACCESS. Execute-only pages are refused. One ReadProcessMemory(GetCurrentProcess()) copies into a512-byte local array; failed/short reads produce one bounded failure status only. No direct guest pointer load, write, protection change, pointer chase, external process open, debugger attach/pause, context capture, stackwalk, fault continuation or settings change occurs.

Only after an exact512B read, one bounded logger record emits128 eight-digit raw big-endian opwords, fixed start/length, import/full LR, guest/native thread IDs, raw r3..r8 and optional host QPC begin/end (explicit read flags). Words come exclusively from the copied local buffer. The fixed1152-character array includes separators/NUL; no per-word log or unbounded formatting buffer. QPC is host observation time. Source bytes/registers are live, noncoherent evidence; no instruction/function/ABI/DPC/due-time claim and no zero-overhead/performance comparison. A future offline decoder must verify the call/import and reaching argument definitions; the512B window may omit necessary predecessors/bounds.

The observer does not need a new title run automatically. All configure/build/tests/game/metadata/read execution remains UNRUN and needs a separate root grant. Four focused CPU cases use `[timer_callsite_bytes]`: exact metadata/import/full-LR rejection, integer/region/protection boundaries, concurrent one-shot/no failure refund, and endian/copy preservation at both local-buffer ends. They do not prove Windows API availability or live phase qualification. The earlier `[native_timer_trace]` three cases remain unchanged.
